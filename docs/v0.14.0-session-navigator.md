# v0.14.0 session navigator

The Session Navigator is the one searchable surface for workspaces, tabs, live
panes, and Unix detached sessions. It opens on demand from `Ctrl+Shift+A`, the
command palette, or the existing Manage Sessions context-menu item. Opening
snapshots the `WorkspaceSet` and, on Unix, the existing session-host registry.
It does not poll, attach, wake, or mutate a session.

Rows use stable arena tokens for live panes and registry ids for detached
sessions. They show a bounded title, local, remote, attached, or detached
class, a bounded working directory or redacted remote host identity, lifecycle
state, unread state, and launch profile. Screen content and command text are
not collected or displayed. Remote identities omit user and port data.

Enter focuses a live pane through the existing workspace switch path or opens
the existing attach flow for a detached session. `r`, `d`, and `m` route
rename, duplicate, and move through the existing tab/workspace paths. `x`
always asks for confirmation before closing a live tab or workspace, while `X`
asks for confirmation before killing a detached session. `o` reopens a fresh
shell in the last closed tab or workspace's recorded directory and profile; it
does not resurrect a process. The bounded 16-item close history is kept only
for the current process. A disappeared target is a safe no-op. Detached sessions are Unix-only;
Windows shows live local and integrated SSH panes and does not claim
detached-session support before Phase 11.

The Attach Choice "Replace current" path is intentionally absent from this
fresh-shell history: its hosted tab becomes a detached registry session, which
remains attachable from the navigator rather than being replaced by a new shell.

Preview is opt-in through `navigator_preview` or `ODYTTY_NAVIGATOR_PREVIEW` and
is off by default. It uses at most eight frozen rows from a live pane, redacts
sensitive assignments, long token-shaped values, and remote identities, and never attaches, wakes, or
writes. Detached rows report `preview unavailable` on Linux and macOS; Windows
does not offer detached sessions before Phase 11.
