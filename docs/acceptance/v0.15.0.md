# v0.15.0 hands-on acceptance

Hands-on pass/fail checklists for the four v0.15.0 feature surfaces. Record each
step as **PASS**, **FAIL**, **SKIP** (with reason), or **UNSUPPORTED**. Do not
claim a platform contract from unit tests alone.

Companion: [manual validation](../manual-validation.md),
[v0.15.0 foundation](../v0.15.0-foundation.md),
[release notes draft](../releases/0.15.0.md).

Quoted strings below are copied from the tree at the checklist authoring
revision. If a notice differs in a later build, treat the running binary as
authoritative and treat the difference as a documentation defect.

---

## 1. Quick terminal

**Prerequisites:** set `quick_terminal = on` and configure
`quick_terminal_shortcut` (default `F12`). Other knobs under test:
`quick_terminal_edge`, `quick_terminal_coverage`, `quick_terminal_span`,
`quick_terminal_monitor`, `quick_terminal_animation`,
`quick_terminal_hide_on_focus_loss`, `quick_terminal_profile`. Restart after
changing non-reloadable knobs. Palette row when enabled:
`Toggle Quick Terminal`.

### 1.1 Linux X11

| # | Platforms | Action | Expected | Fail if |
| --- | --- | --- | --- | --- |
| QT-X11-01 | Linux X11 | Start with `quick_terminal = on`. After the first usable frame, press the configured global shortcut. | Quick terminal appears from the configured edge; a usable prompt is ready. | No window, delayed first ordinary window, or silent no-op. |
| QT-X11-02 | Linux X11 | Press the same shortcut again. | Window hides; the quick session stays alive (no shell restart). | Session restarts, PTY exits, or a second quick window appears. |
| QT-X11-03 | Linux X11 | Summon, type a unique marker, hide, summon again. | Marker text and cursor state remain. | Fresh shell or lost scrollback. |
| QT-X11-04 | Linux X11 | Rapidly press the shortcut 10+ times. | At most one quick-terminal window; end state is either shown or hidden, never duplicated. | Two or more quick windows, or a stuck half-shown state. |
| QT-X11-05 | Linux X11 | With a full-screen app focused, press the summon shortcut. | Behavior matches the platform grab: either the quick terminal appears above, or the compositor blocks the grab with an actionable notice. Never a silent success claim. | Silent failure with no notice, or claimed registration without a working grab. |
| QT-X11-06 | Linux X11 | Multi-monitor: set `quick_terminal_monitor` to `active`, then `primary`, then an index. Summon on each. | Geometry anchors to the configured monitor policy. | Wrong monitor, clipped off-screen, or crash on display change. |

## 2. External file drop

**Shared policy:** dropped local paths use shell-aware quoting, open the existing
risky-paste confirmation when required (`warn_on_risky_paste`), never append
Enter, and never auto-execute. Confirm with **Paste**; cancel with **Cancel**.
**Paste as One Line** must not appear for file-drop batches.

### 2.1 Linux (X11 and Wayland)

| # | Platforms | Action | Expected | Fail if |
| --- | --- | --- | --- | --- |
| FD-L-01 | Linux X11 + Wayland | Idle bash prompt; drop a file whose name contains spaces and quotes (synthetic fixture). | Confirmation preview lists the path; Paste inserts a shell-safe quoted path; no trailing Enter; shell does not run the path as a command. | Enter appended, unquoted metacharacters, or immediate execution. |
| FD-L-02 | Linux | Drop a Unicode filename (non-ASCII). | Lossless insert after confirm, or refuse with `This path cannot be inserted losslessly with the active shell. Copy the path manually or cancel.` | Moji-bake, truncated path, or silent drop. |
| FD-L-03 | Linux | Drop multiple files in one gesture. | Preview order matches drop order; Paste inserts all quoted paths in that order without Enter. | Reordered, truncated list, or Enter after the batch. |
| FD-L-04 | Linux | Drop a directory. | Path inserts as a quoted directory path (not recursive contents), no Enter. | Recursive upload, open-in-file-manager side effect, or Enter. |
| FD-L-05 | Linux | Drop a non-UTF-8 path fixture if the file manager can produce one. | Refuse with the UnsupportedPath notice above, or insert via the shell's non-UTF-8-safe form without corruption. Never claim success for a corrupted string. | Corrupted bytes pasted as if valid UTF-8. |
| FD-L-06 | Linux | Bash, then zsh, then fish idle prompts: drop the same spacey path. | Each shell receives its quoting form; no Enter. | Wrong shell quoting, or fish/zsh treated as bash. |
| FD-L-07 | Linux | Start a foreground job (`sleep 30`); drop a file. | Refuse with: `File insertion could not verify the local launch shell alone in the foreground. Return to the launch shell and stop its jobs, or copy the path manually if this platform cannot verify ownership.` | Path inserted while a job owns the TTY. |
| FD-L-08 | Linux | Open Settings (or Theme Picker); drop a file. | Refuse with: `Close the current dialog before dropping files.` Pending drop cleared if a dialog opens after a drop started. | Insert behind the overlay, or stuck pending confirm. |
| FD-L-09 | Linux | Focus a remote or attached pane; drop a local file. | Refuse with: `Drop files into a local shell. Remote and attached panes do not accept local paths.` | Local path written into the remote/attached session. |
| FD-L-10 | Linux | Oversized batch (more than 128 files or more than 256 KiB of path bytes). | Refuse with: `Drop fewer files (at most 128 files and 256 KiB of paths).` | Partial insert or hang. |
| FD-L-11 | Linux | Cancel mid-confirm; drop again. | Cancel clears pending state; second drop starts clean. | Stale preview, double insert, or Paste of the cancelled batch. |

### 2.2 macOS

| # | Platforms | Action | Expected | Fail if |
| --- | --- | --- | --- | --- |
| FD-MAC-01 | macOS | Repeat FD-L-01..04 and FD-L-06..11 with Finder drops into a local shell. | Same notices and no-Enter contract as Linux. | Platform-specific silent accept on remote panes or while a job runs. |
| FD-MAC-02 | macOS | Unicode and Apple-decomposed filename drop. | Lossless quoted insert or UnsupportedPath refuse. | NFD/NFC corruption accepted as success. |

### 2.3 Windows (explicit refusal)

| # | Platforms | Action | Expected | Fail if |
| --- | --- | --- | --- | --- |
| FD-WIN-01 | Windows | Drop a file onto a local ConPTY shell. | Insertion is refused with: `File drop insertion is not available on Windows in this version. Copy the path manually.` | Path inserted, a success toast, or the generic job-control notice. |
| FD-WIN-02 | Windows | Drop onto a remote/attached pane or with Settings open. | Still refused; NonLocalPane / overlay notices may appear instead when those conditions apply first. | Any successful path insert. |

## 3. Keyboard-first window merge

User-visible command palette rows (only when another window exists):

- `Merge This Window Into...`
- `Pull Window Into This One...`

Session Navigator legend (when merge targets exist): `i merge window`,
`p pull window`.

| # | Platforms | Action | Expected | Fail if |
| --- | --- | --- | --- | --- |
| WM-01 | Linux / macOS / Windows | Open two ordinary windows with distinct tabs. Palette: `Merge This Window Into...`. | Candidate windows show temporary numerals; pressing a numeral completes the merge; source window closes only after success; tabs/panes/PTYs survive in the target. | Source closes before transfer, lost PTY, or no numerals. |
| WM-02 | Linux / macOS / Windows | From the other window: `Pull Window Into This One...` and select. | Selected window's sessions move into the origin; source closes after success. | Wrong direction, duplicate tabs, or orphan window. |
| WM-03 | Linux tiling compositor without decorations | Open merge picker; confirm numerals paint inside candidate surfaces without compositor plugins. | Numerals visible and selectable from the keyboard. | Numerals missing, or merge requires a mouse-only OS picker. |
| WM-04 | All | Start merge picker; press Escape / cancel. | Picker dismisses; no transfer; both windows intact. | Partial move or stuck picker. |
| WM-05 | All | Start merge picker; close the candidate window before selecting. | Picker fails closed (no transfer, clear stale target); no panic. | Crash, merge into a dead id, or silent corruption. |
| WM-06 | All | Merge a window that has an attached session handle and a live local PTY. | Attach handle and PTY remain usable in the destination after transfer. | Detached session dropped, or PTY killed by the merge. |

## 4. Local automation

**Prerequisites:** `automation_endpoint = on` (also `ODYTTY_AUTOMATION_ENDPOINT`).
Off by default. CLI: `odytty control --endpoint <path> ...` with
machine-readable or human-readable output and no shell interpolation of
arguments.

### 4.1 Linux

| # | Platforms | Action | Expected | Fail if |
| --- | --- | --- | --- | --- |
| AU-L-01 | Linux | Start with `automation_endpoint = off`. | No control socket under `$XDG_RUNTIME_DIR/odytty/` before or after the first frame. | Socket created while the setting is off. |
| AU-L-02 | Linux | Enable `automation_endpoint = on` (config or live reload). | After the first usable frame (not before), an owner-private socket appears (name pattern `control-<pid>.sock`). Default terminal is not delayed by endpoint setup. | Socket before first frame, world-writable socket, or startup stall. |
| AU-L-03 | Linux | `odytty control --endpoint "$XDG_RUNTIME_DIR/odytty/control-<pid>.sock" status` (or equivalent list/status). | Machine-readable success; lists non-sensitive window/workspace/tab structure only. | Terminal contents returned, or secret-bearing defaults. |
| AU-L-04 | Linux | Structural actions: focus, open profile/tab/split as documented. | Actions apply; input/send-text and content-read remain unavailable. | Implicit send-text or screen scrape succeeds. |
| AU-L-04b | Linux | Open Settings (or search, copy mode, or a tab rename) in the target window, then send focus/split/rename. | Reply is the `busy` error; `status` still answers. Close the dialog and retry: the action applies. | Mutation applied beneath the open dialog, or a pane switch that leaves copy mode or rename active on the wrong pane. |
| AU-L-04c | Linux | With the quick terminal hidden, send `focus` for one of its objects. | Reply is the `unavailable` error and the quick window stays hidden; the global shortcut still summons it. | `applied` reply with no visible window. |
| AU-L-05 | Linux | Set `automation_endpoint = off` (reload). | Socket is removed; further CLI calls fail cleanly. | Stale listening socket left behind. |
| AU-L-06 | Linux | Start a second OdyTTY instance with automation on. | Second instance does not unlink the first instance's socket; each owns its endpoint. | First socket deleted when the second starts. |
| AU-L-07 | Linux | Unset or replace `XDG_RUNTIME_DIR` with a non-owner-private path. | Endpoint unavailable; notice includes: `Local automation unavailable; XDG_RUNTIME_DIR must name an owner-private runtime directory.` | Listener starts on a shared directory. |

### 4.2 macOS

| # | Platforms | Action | Expected | Fail if |
| --- | --- | --- | --- | --- |
| AU-MAC-01 | macOS | Mirror AU-L-01..06 using the owner-private state-directory endpoint path from the log/docs. | Same owner-only and no-before-first-frame contracts. | World-readable socket, or startup delay. |
| AU-MAC-02 | macOS | Force a state-directory failure (permissions). | Notice: `Local automation unavailable; check the OdyTTY log for the owner-private state-directory error.` | Silent listen on an insecure path. |

### 4.3 Windows

| # | Platforms | Action | Expected | Fail if |
| --- | --- | --- | --- | --- |
| AU-WIN-01 | Windows | Enable `automation_endpoint = on` before named-pipe support is enabled. | No listener; user-visible notice: `Local automation is unavailable on Windows until named-pipe support is enabled.` | Silent success, TCP listen, or any network bind. |
| AU-WIN-02 | Windows | After named-pipe support lands, re-run AU-L-01..06 adapted to the pipe path and flip this row's expected text to the pipe contract. | Owner-only pipe; no network; disable removes the pipe; second instance does not steal the first. | Cross-user pipe ACL, or first instance endpoint stolen. |

### Findings (docs / product gaps to watch during hands-on)

1. **Windows file drop refuses by platform.** The Windows notice names the
   platform rather than the job-control check; any successful insert is FAIL.
2. **Comment vs palette casing.** Internal comments often say
   `Merge this window into...` while the palette shows
   `Merge This Window Into...`. Checklists quote the palette.
3. **AU-WIN-02 is flip-ready.** Until named pipes land, mark AU-WIN-02 SKIP and
   keep AU-WIN-01 as the Windows automation contract.
4. **Wayland no-portal compositor bind (QT-WL-NP-02)** depends on desktop-specific
   documentation; SKIP with reason is acceptable when no supported bind path
   exists for that compositor.
