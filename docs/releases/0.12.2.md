# OdyTTY v0.12.2

A focused fix for overlapping and misplaced progress output.

## Multiline progress updates stay on their rows

Programs such as pacman use cursor-next-line and cursor-previous-line controls
to update individual progress rows. OdyTTY previously ignored those controls,
which could leave package names, counters, and progress bars overlapping or
appearing out of order.

Both controls now move to the requested row and return to the left margin,
including when the count is omitted or reaches a screen boundary. This corrects
the terminal behavior behind the reported parallel-download display problem.

## Updating

This is a narrow terminal-correctness patch over v0.12.1. Update through your
existing installation channel; no configuration change is required.
