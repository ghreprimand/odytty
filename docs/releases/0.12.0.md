# OdyTTY v0.12.0

Lower memory use, additional graphics compatibility, and verifiable build provenance.

## Use less memory for the same terminal work

Background images are sized to the drawable surface, unused post-processing
targets are released, and scrollback uses denser storage. Font fallback shares
parsed font faces and avoids retaining an entire oversized font collection when
only one face is needed.

Together, these changes address excessive memory use in the reproduced CJK
font-fallback workload and reduce memory in the measured idle workload. Results
are specific to the documented workloads; they are not a promise of a fixed
memory footprint for every session.

## Broader inline-graphics support

Kitty graphics gains bounded zlib-compressed payload support and animation
addressing by image number. Terminal capability reporting now advertises the
existing Sixel implementation, helping applications recognize that support.

## Verify where a release came from

Release artifacts now include GitHub build-provenance attestations alongside
the existing Minisign-signed checksum manifest. These provide a way to check the
build's origin as well as the downloaded file's integrity.

## Updating

Update through your existing installation channel. Full bidirectional text
layout, complex Indic/Brahmic reordering, and SVG-in-OpenType glyphs remain
outside this release's text support.
