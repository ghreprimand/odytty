# OdyTTY v0.16.1

The only change in version 0.16.1 is AppImage update information and its
companion zsync asset. Every other package is rebuilt at 0.16.1 with no
behavior change from 0.16.0: Linux tarballs, Debian and RPM packages, Windows
and macOS zips, the source archive, and Scoop, Homebrew, and AUR packages.

## What this release adds

- **AppImage update information.** The x86_64 AppImage embeds a channel for
  the latest OdyTTY GitHub release, and the release includes
  `odytty-x86_64.AppImage.zsync`. AppImage update tools such as AppImageUpdate can use this
  control file to check for and download updates. The control file describes
  the always-latest alias; the version-pinned AppImage contains identical
  bytes. Both the image and control file are covered by signed SHA256SUMS
  and build provenance. Zsync's SHA-1 checks transfer integrity and does not
  replace release authentication. OdyTTY initiates no automatic update check.
  Version 0.16.0 and earlier have no update information, so replace those
  AppImages manually once to reach an update-capable version.

## Updating

Update through your existing installation channel. AppImages from v0.16.0 and
earlier carry no update information, so replace them manually once.
