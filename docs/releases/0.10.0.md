# OdyTTY v0.10.0

Clearer everyday feedback and a stronger reliability foundation.

## See terminal size and activity at a glance

OdyTTY shows the live terminal dimensions while resizing and the effective font
size during Ctrl+wheel zoom. Tabs and workspaces also surface unseen activity,
helping you keep track of work away from the active pane.

## More predictable input and failures

Windows keypad and Ctrl-key records preserve their intended key identities.
Detached-session output is bounded, and failures to create a window produce an
error instead of failing silently.

## Tighter input and file-handling boundaries

Externally influenced file reads receive size limits, with checks that reject
inappropriate file types in the affected paths. Clipboard images are checked for
dimensions and byte limits before expensive encoding.

Much of this release is internal: large modules were split along their ownership
boundaries, and parser, input, graphics, and transport regression coverage was
expanded. The aim is a terminal that is easier to maintain without changing its
core behavior.
