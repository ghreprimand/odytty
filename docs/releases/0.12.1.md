# OdyTTY v0.12.1

A security fix for reused SSH connections.

## Keep different SSH destinations separate

OdyTTY now uses OpenSSH's effective connection identity when reusing an SSH
connection. Connections to different ports or remote users no longer risk sharing
the same OdyTTY-generated multiplexing socket simply because their textual
destinations look alike.

Interactive connections, remote image uploads, and uploaded-image cleanup all
use the corrected identity. The release also restricts the AUR publication
workflow to the credential it needs.

## Updating

Users of OdyTTY's integrated SSH connections should update. This is a focused
patch over v0.12.0 and does not add new connection settings.
