# OdyTTY v0.14.0

Named profiles, desktop palette following, and a single place to find your sessions.

## Set up a workflow once, launch it again

Named profiles bring your shell or command, starting directory, environment
overrides, theme, cursor, effects, and layout together in a reusable configuration.
Create and edit them in Profile Manager, duplicate an existing setup, or import
and export profiles to share a configuration without storing credentials.

Choose a global default and, when needed, a different default for a workspace.
The ordinary **+** button and New Tab shortcut still open a terminal immediately;
the adjacent searchable chooser lets you pick another profile. Profiles also work
with the command palette, CLI, saved layouts, connections, and restoration.

## Follow a local desktop palette

The new opt-in **Follow desktop palette** mode watches a selected local palette
file and applies valid color changes live. If the file temporarily disappears or
contains an incomplete update, OdyTTY keeps the last working palette.

Supported formats include Omarchy-compatible `colors.toml`, pywal-compatible
`colors.json`, and explicit OdyTTY/Base16/ANSI palette files. Compatibility is
independent of those projects. Existing theme behavior stays unchanged unless
following is selected.

## Find and manage sessions in one place

Press **Ctrl+Shift+A** to open the Session Navigator. Filter workspaces, tabs,
panes, and supported local or remote sessions; jump to a pane or attach a detached
session without hunting through tabs and menus.

Row context menus offer the actions available for that target, including rename,
duplicate, move, close, and reopen. Closing a pane preserves its siblings, and
destructive actions ask for confirmation. An optional preview shows a short,
redacted excerpt of recent visible output.

Windows supports navigation of live workspaces, tabs, and panes; detached-session
hosting and attach remain unavailable there. Preview redaction is bounded and
should not be treated as a guarantee that all sensitive text is detected.

## Other improvements

- Cycle tabs with **Ctrl+Shift+;** and **Ctrl+Shift+'** as alternatives to
  Ctrl+PageUp/PageDown. The new shortcuts are rebindable and unavailable on layouts
  where those keys carry letters.
- Profile and navigator controls have corrected click targets, scrolling, and
  shortcut legends that wrap in narrow windows.
- Targeted hardening improves paste handling, configuration writes, profile
  environment validation, image parsing, and session transport error handling.
- The Linux installer is now a version-pinned release asset covered by the signed
  checksum manifest, so it can be verified before execution.

## Updating

Update through the same channel used to install OdyTTY. External palette following
and navigator previews are opt-in; an update does not enable them automatically.
