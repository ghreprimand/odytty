# OdyTTY v0.13.0

Safer pasting, useful actions on command output, and better awareness of work running in other panes.

## Preview risky pastes

When an application has not enabled bracketed paste, OdyTTY now asks before
sending multiline or control-bearing text to the terminal. The preview shows
escaped text and line and byte counts, with **Paste**, **Paste as One Line** when
available, and **Cancel** choices.

Ordinary single-line text and pastes into applications using bracketed paste keep
their existing behavior. The warning helps prevent accidental input; it does not
judge whether a command is safe to run.

## Work with one command's output

Use the command palette or terminal context menu to select, copy, search, or
export a command's output. Select and copy can include the prompt and command
line, and failure navigation jumps to commands with a reported nonzero exit status.

These actions use command boundaries supplied by shell integration. If the
required boundaries are missing or no longer available, the action is disabled
rather than guessing from the text on screen. Export writes bounded plain text to
a location you choose.

## Keep track of running work

One-shot monitors in the command palette can watch for command completion,
failure, activity, silence, a bell, or process completion. Applications that emit
supported progress sequences can also report progress in OdyTTY.

Notices belong to the pane that produced them, use bounded presentation, and do
not steal focus. In-app presentation is the default; native desktop delivery
follows the notification settings. Existing terminal-bell behavior is preserved.

## Updating

Update through your existing installation channel. Command-output actions require
shell integration that supplies the relevant command markers; they are not
available for arbitrary alternate-screen application content.
