# OdyTTY v0.11.1

A more predictable and readable Theme Builder.

## Back returns to the right place

Opening Theme Builder from Settings and pressing Esc now returns to the Themes
section instead of closing the entire settings overlay. Leaving the builder also
avoids stranding the settings panel at the wrong navigation level.

## Controls stay readable while editing

The keyboard reference stays visible after changing a value. Status messages use
a fixed-height area, so updates no longer push the controls and color-role list
around. The header groups the theme name, contrast information, slider, and help
more clearly.

## Updating

This patch focuses on the Theme Builder's navigation and layout. Update normally;
no theme-file changes are required.
