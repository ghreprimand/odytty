# OdyTTY v0.15.0

Unreleased development on `master`. No tag, package, or published release
claim.

Electric Blue adds the `odyssey-electric-blue` preset: a blue-black background,
lavender text, an electric cyan cursor, and distinct ANSI colors. It uses the
existing shared theme parser, picker, settings, and export paths on Linux,
macOS, and Windows without changing the default preset or effect settings.

## Landed with unit evidence

These surfaces are in `master` with retained local tests. Full platform device
acceptance remains incomplete; this is not a release.

- **Quick terminal.** Dedicated identity and settings, platform shortcut
  adapters (Linux X11, Wayland portal or actionable limitation, macOS, Windows),
  hidden-session retention, single-instance summons, monitor fallback, and
  registration only after an ordinary frame, and actionable notices for
  denied or conflicting registrations. Evidence includes `ac302da5` and
  `86affd5b`. Native Wayland hide releases and recreates presentation objects
  while retaining sessions and stable identities, clears focus/input state,
  and suppresses render timers while hidden. Two hide/summon cycles, including
  a two-tab quick session, passed on Hyprland. Placement remains
  compositor-controlled; fullscreen and display-reconfiguration checks remain
  open.
- **Local automation.** Opt-in `automation_endpoint` (default off) binds after
  the first presented frame. Linux and macOS use owner-private sockets; Windows
  uses `\\.\pipe\odytty-control-<pid>` with an owner-only DACL, remote-client
  rejection, and mutual SID checks. The protocol is structural only (no terminal
  input or content reads). Its quick-terminal toggle gives Wayland compositors a
  real bind target; bare Unix discovery requires exactly one eligible instance,
  while Windows remains endpoint-explicit. Busy, unavailable, and listener-fault
  contracts and hostile-client suites are covered in-tree. Evidence includes `fc195b45`,
  `57be9201`, `7bc45b4b`, `a4bce1df`, and `1a74e44d`.
- **File drop.** Confirm-first shell-quoted insertion on eligible local Unix
  panes through the shipped paste-safety policy; no Enter. Windows refuses with
  an explicit platform notice. Remote and attached panes refuse local paths.
  Integrated-SSH clipboard-image upload remains a separate confirm-first path
  that native path drops never enter. Native Wayland delivery (winit emits no
  Wayland drop event) is supplied by a companion non-owning `wl_data_device` on
  compositors that honor copy action negotiation; it is not started on Hyprland
  (which cannot negotiate copy safely) and shows an actionable notice there.
  Evidence includes `c64334f9` and `0b38b26e`; native-Wayland delivery is
  unit- and nested-compositor-tested, with per-compositor device acceptance
  still open.
- **Keyboard-first window merge.** Palette and Session Navigator merge/pull with
  in-window numerals and atomic same-process transfer of tabs, panes, PTYs, and
  attach handles.

## Still open before release

- Real-device acceptance for quick-terminal shortcuts, fullscreen, multi-monitor,
  virtual desktops, display reconfiguration, and crash behavior
- Real-device file-drop delivery on X11, Wayland, macOS, and Windows
- Hands-on window-merge numerals on tiling compositors and multi-window transfer
- Hands-on Windows remote-client and cross-account automation refusal
- Blocking three-OS CI for the release checkpoint, packaging, signed artifacts,
  and Homebrew/Scoop/AUR propagation
