# OdyTTY v0.15.0

Unreleased development. Electric Blue is available in source while the release
features, platform acceptance, complete gates, and packaging remain in progress.

Electric Blue adds the `odyssey-electric-blue` preset: a blue-black background,
lavender text, an electric cyan cursor, and distinct ANSI colors. It uses the
existing shared theme parser, picker, settings, and export paths on Linux,
macOS, and Windows without changing the default preset or effect settings.

Current unreleased foundations also add stable tab and workspace identities,
same-process window merge routing, quick-terminal settings and platform shortcut
backends, and an opt-in bounded structural-control endpoint with an explicit
Unix CLI. The endpoint is off by default and begins live owner routing on Linux
or macOS only after the first presented frame. Windows named-pipe transport,
file-drop device validation, remaining live-window behavior, independent
platform acceptance, blocking CI, and packaging remain open. See the
[v0.15.0 contracts](../v0.15.0-foundation.md) for the detailed boundaries.
