# OdyTTY v0.17.0

Version 0.17.0 improves international text on the terminal cell grid: script
clusters and emoji sequences keep their cells, complex scripts are shaped with
the font, right-to-left text can be drawn in display order, and new font and
symbol rendering arrives. Cells, cursor addressing, selection, search and
copied text stay in logical order throughout.

## Shaping settings and existing configurations

`ligatures` now controls only Latin and programming-operator ligatures and the
optional `ss01`/`ss02` sets. The new `script_shaping` setting controls Arabic
joining, harakat positioning and complex-script shaping, and is on by default.
Existing configurations with `ligatures = off` therefore get Arabic joining
and complex-script shaping back; set `script_shaping = off` to keep per-cell
drawing for those scripts. Both rows are in Settings > Rendering and apply
live.

## Text and display

- **Script clusters and widths.** Devanagari, Bengali, Gurmukhi, Gujarati,
  Odia, Tamil, Telugu, Kannada, Malayalam, Sinhala, Khmer, Myanmar, Thai, Lao,
  Tibetan, Chakma, Javanese, Grantha and Tai Tham clusters stay together in
  bounded cell spans, including when program output splits them across reads.
  Editing, wrapping, reflow, search and copy keep the original text.
- **Emoji sequences.** Emoji with VS16, skin-tone modifiers, keycaps, flag
  pairs and recognized ZWJ sequences take their defined two cells. Text
  presentation (VS15) and a lone regional indicator keep their previous width.
- **Combining marks.** The glyph atlas follows Unicode 17.0.0 nonspacing
  and enclosing marks, excluding variation selectors, when drawing marks over
  their base cell. Spacing marks draw from their own pen position.
- **Ambiguous-width setting at startup.** `ambiguous_width = wide` applies
  from the first window, including new tabs, split panes, workspaces, attached
  sessions and SSH connections. Profile launches use the profile-merged
  setting. Greek and Cyrillic letters remain one cell.
- **Font shaping for complex scripts.** With `script_shaping` on, these
  scripts and Arabic joining runs, including harakat, are shaped with the
  font. A fallback script font starts at the terminal font's size. A run
  wider than its cells shrinks to fit, never below 60 percent; ink still wider
  at that floor is clipped on the right. Runs also shrink when their ink
  exceeds the available vertical space, including the mark overflow allowance.
  Shaped runs keep their fixed cell spans, and text the font does not fully
  cover keeps per-cell drawing. Complex-script shaping never crosses a cluster,
  and the block cursor shows per-cell glyphs. One Bengali sequence
  (ka, virama, ra) is shaped differently from the HarfBuzz reference; the
  [text shaping reference](../shaping-roadmap.md#current-support-boundary)
  lists this and the other limits.
- **Windows and macOS script fallback.** After the static font chain misses,
  script fallback loads stock system faces on the runtime worker, on first
  need, without delaying startup. Complex-script clusters use the same fallback
  faces. Disabling symbol fallback disables this chain too. A missing face
  leaves its script boxed; macOS ships no Grantha face. Linux fontconfig
  fallback is unchanged. The [feature reference](../features.md#render-text-and-symbols)
  records the script-specific face order and bounds.
- **Bidirectional display, off by default.** `bidi_reorder` (Settings >
  Rendering > Bidirectional text, or the right-click Reorder Right-to-Left
  Text toggle) draws right-to-left runs such as Hebrew and Arabic in display
  order on the primary screen, with a left-to-right paragraph level. The
  alternate screen used by full-screen programs is never reordered, there are
  no right-to-left paragraph levels, and image placements are not reordered.
  Cursor addressing, selection, copy, search, scrollback export and mouse
  reports stay logical, so a selection that crosses a direction change can
  show as separate segments while copy returns the logical text. Reordered
  terminal text stays reordered while menus and panels are open.
- **Alternate zero.** Settings > Fonts > Alternate zero, off by default,
  applies the font's OpenType `zero` feature without changing cell size or
  baseline. Open-ended stylistic sets and arbitrary raw font feature tags remain
  unsupported.
- **SVG color glyphs.** SVG-in-OpenType glyphs draw in the same one- or
  two-cell color slot as other color glyphs, only where no bitmap or COLR
  source covers the glyph; faces whose only color data is SVG rank after every
  named and COLR emoji face. Oversized documents, patterns, filter, mask or
  marker elements and attributes, their CSS property declarations, and
  stylesheet `url(` references fall back to monochrome. The words `filter`,
  `mask` and `marker` in class names, font names or comments do not cause a
  refusal.
  SVG text is not drawn, and no scripts, files, network resources or embedded
  images are loaded.
- **Legacy computing diagonals.** The diagonal fills U+1FB3C to U+1FB67 and
  U+1FBBD to U+1FBBF are drawn by an antialiased polygon filler that meets
  neighbouring cells without gaps.
- **More color glyphs.** The color glyph cache holds 16,384 glyphs instead of
  4,096, within the graphics device's texture limit and a 256 MiB ceiling.

## Windows, tabs and sessions

- **Live tab drag, on by default.** Dragging a tab out of the strip shows a
  window that follows the pointer on Hyprland, Wayland compositors that
  advertise `xdg-toplevel-drag` (KDE Plasma and GNOME tested), macOS and Windows.
  Releasing commits the
  move once; Escape or returning to the strip restores the tab exactly. Other
  Wayland compositors create the window on release, and the compositor places
  it. Settings > Layout > Live tab drag turns following off.
- **Launching with arguments.** A launch with any command-line argument does
  not restore the saved layout and never writes it, so the layout saved by the
  last plain launch is kept. Linux, macOS and Windows behave the same.
- **Broadcast to one pane.** When the focused pane is the only broadcast
  receiver, its label reads `BROADCAST this pane only` (`BC self` when narrow)
  instead of `BROADCAST 1`.

## Other corrections

On Windows, when a program has turned on Win32 input mode, a key after a dead
key that cannot combine with it sends both characters. Saved layout names keep
visible non-ASCII text within their 96-byte limit. Names containing non-ASCII
visible text compare by exact characters, so an emoji ZWJ family stays distinct
from its separate member emoji. ASCII-only names still ignore ZWJ, ZWNJ, VS15
and VS16 when checking for a clash.

Bash shell integration preserves the preceding command's last argument (`$_`)
and status with or without an existing DEBUG hook, including with `functrace`
and `extdebug`. Zsh, fish and PowerShell use separate hooks and are unchanged.
The Unix interactive frontend keeps readable output within a fixed 256 KiB
bound when its reader is forced to EOF, and presents the final terminal state
on an unexpected reader disconnect. Windows keeps its ConPTY behavior and does
not offer this frontend.

SSH sign-in checks read the whole error output. The tarball installer refuses
destinations that resolve into the package-managed `/usr` tree, including
merged-directory aliases.

## Platform acceptance

Rendering and scripts passed hands-on checks on Hyprland, Windows and macOS.
On Linux, Tamil and the second Javanese word are visibly squeezed to their
cells. Windows and macOS draw these lines from stock system fonts; macOS has
no stock Grantha face. The right-to-left toggle, its check mark and logical
copy and paste passed on Hyprland, Windows and macOS. Reordered right-to-left
text stayed reordered under the right-click menu and Settings on Hyprland,
Windows and macOS. Alternate zero and Legacy Computing diagonals passed on all three platforms. Changing the Hyprland
monitor scale kept text sharp; X11 through Xwayland at 1.5 scale was sharp and
aligned; changing the macOS display scale passed. Windows rendering passed
without a scale change. Live tab drag with Escape cancellation passed on
Hyprland, Windows, macOS, KDE Plasma Wayland and GNOME Shell 50.1 Wayland.
Argument launches preserved the saved layout, and the one-pane broadcast label
passed, on Hyprland, Windows and macOS.
SVG color glyphs are covered by synthetic SVG-only fixture fonts on the Linux,
macOS and Windows test runs.
