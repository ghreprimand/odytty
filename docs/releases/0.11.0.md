# OdyTTY v0.11.0

Richer inline graphics, color-vector emoji, theme capture, and signed release checksums.

## More ways to display images and emoji

OdyTTY adds Kitty graphics animation and Unicode image placeholders, plus iTerm2
inline images. Fonts using COLR/CPAL color-vector glyphs can render in color,
including Windows Segoe UI Emoji that previously fell back to monochrome.

Support remains format-specific: this release does not yet support compressed
Kitty payloads, animation addressing by image number, or chunked iTerm2 `File=`
transfers.

## Turn the current colors into a theme

The new **Create theme from current colors** flow captures the focused pane's
live palette and opens it as a draft in Theme Builder. It supplies derived values
for interface colors that terminal color sequences cannot specify, ready for
review and editing before saving.

## Better font discovery and shaping

Startup shares a font inventory across fallback discovery instead of repeatedly
walking the same font directories. Presentation shaping expands to more ligature
features and Arabic contextual joining while keeping the terminal cell model.
Arabic joining does not include right-to-left layout; full bidi and complex-script
reordering remain unsupported.

## Authenticate downloads

Releases now include a Minisign signature for `SHA256SUMS`, with a published
verification key. This authenticates the checksum manifest before it is used to
check a download. macOS apps remain ad-hoc signed rather than notarized, and
Windows executables remain unsigned.

## Other improvements

The renderer uses compact instances for cell geometry, and the documentation now
more clearly describes the supported graphics, font, and platform boundaries.
