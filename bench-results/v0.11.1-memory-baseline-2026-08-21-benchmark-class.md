# v0.11.1 idle memory baseline, benchmark environment class

Capture date: 2026-08-21.

This dated baseline is an auxiliary Phase 0 memory-attribution record. It is
not a protocol result, is not pooled with W6, and does not supersede the
published benchmark record.

## Public environment class

Linux, x86_64 desktop class with 8 logical cores; Hyprland v0.56.2 native
Wayland; Intel UHD Graphics 620 with the `i915` kernel driver and distribution
Mesa; 8-16 GiB memory class; external AC power with the performance CPU policy;
1920x1080 at 60.010 Hz, scale 1.0. This is the benchmark-machine environment
class recorded by the benchmark protocol. No machine identifier, account name,
or filesystem path is retained here.

## Subject and method

- Subject: OdyTTY `v0.11.1`, tag commit `82392d072ced6b486eb1beaa0e0f05da68ad4598`.
- Build: clean isolated clone, release build.
- Workload: idle visible terminal, default configuration, 640x400 pixel window.
- Replicates: two fresh launches, captured after startup reached idle.
- Capture: `scripts/memory-capture.py`, schema `odytty-memory-capture/1`,
  Linux `smaps_rollup` plus `smaps`. Both records were `complete`; neither
  required an unavailable-field substitution.
- Units: decimal MB below, with byte values retained for audit. Mapping names
  are basenames only.

`v0.11.1` predates `ODYTTY_MEMORY_REPORT`, so this record is host-side only.
It attributes process mappings and cannot infer OdyTTY-owned GPU allocation
bytes.

The driver-library figure is a mapping classification, not an OdyTTY-owned
allocation estimate. This record separates the graphics-stack component from
the process total; it does not soften the total.

## Provenance and limits

The raw, complete captures survived from the prior Phase 0 capture session and
were validated for this record. They were made with the same host-side script
and 640x400 pinned geometry documented in the Phase 0 measurement report.
This record retains no terminal content, command line, hostname, username, or
full path. It is intentionally an idle baseline only: it establishes neither
scrollback retention nor time-based memory growth.
