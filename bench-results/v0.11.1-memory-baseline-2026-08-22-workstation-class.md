# v0.11.1 idle memory baseline, workstation environment class

Capture date: 2026-08-22.

This dated baseline is an auxiliary Phase 0 memory-attribution record. It is
not a benchmark-machine result, is not pooled with W6, and must never be cited
as a protocol comparison figure.

## Public environment class

Linux, x86_64 workstation class; native Wayland under Hyprland; NVIDIA discrete
graphics adapter. This development-workstation record is deliberately separate
from the benchmark environment class. No machine identifier, account name, or
filesystem path is retained here.

## Subject and method

- Subject: OdyTTY `v0.11.1`, tag commit `82392d072ced6b486eb1beaa0e0f05da68ad4598`.
- Build: fresh release build from an isolated shallow clone of the release tag.
  The shared checkout was not used or modified.
- Workload: idle visible terminal, empty temporary XDG configuration, cache,
  data, and temporary directories, 640x400 pixel floating window, `sleep 35`
  child command to retain the terminal while sampled.
- Replicates: two fresh launches. The window was located by process ID and
  pinned through the compositor before sampling.
- Capture: `scripts/memory-capture.py`, schema `odytty-memory-capture/1`,
  Linux `smaps_rollup` plus `smaps`. Both records were `complete`; neither
  required an unavailable-field substitution.
- Units: decimal MB below, with byte values retained for audit. Mapping names
  are basenames only.

`v0.11.1` predates `ODYTTY_MEMORY_REPORT`, so this record is host-side only.
It attributes process mappings and cannot infer OdyTTY-owned GPU allocation
bytes. On this discrete-GPU environment, releasing a GPU texture also need not
change process RSS.

## Provenance and limits

The isolated clone was checked out directly at the release-tag commit and
built with `CARGO_BUILD_JOBS=4`. Both subjects were confirmed terminated after
capture. This record retains no terminal content, command line, hostname,
username, or full path. It is intentionally an idle baseline only: it
establishes neither scrollback retention nor time-based memory growth.
