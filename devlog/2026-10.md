## 2026-10-02 -- Release v0.15.8 -- macOS idle CPU fix

Version 0.15.8 is a patch release cut from a `release/0.15.8` branch of
v0.15.7, so the v0.16.0 development tree is not included.

On macOS, an untouched window's idle CPU returns to about zero. The cause was
a per-tick clone of the event-loop proxy inside `about_to_wait`, which
re-woke the macOS run loop. The clone has been present since v0.15.0. The
tick path no longer clones the proxy.

On Linux and Windows, proxy clones are cheap and showed no spin. The per-tick
clone is removed there too. This release makes no idle-CPU claim for those
platforms. It makes no rendering-throughput, startup, or memory claim, and the
v0.12.0 results remain the applicable comparative evidence.
