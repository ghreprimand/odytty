# Nerd Fonts Symbols Only glyph licenses

OdyTTY bundles `SymbolsNerdFontMono-Regular.ttf` from the Nerd Fonts
`NerdFontsSymbolsOnly` release archive, v3.4.0. The bundled binary is unmodified.

The font-level license shipped by Nerd Fonts is `LICENSE` in this directory
(MIT). Nerd Fonts Symbols Only aggregates glyphs from multiple upstream icon
sets. Those source projects keep their own licenses and trademarks.
